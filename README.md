CS 141 Habit Tracker Project

The purpose of this application is to aid in smoking cessation.
Smoking has claimed the lives of millions of people, and disproportionately impacts marginalized communities.

To use the app:

Select an option from the main menu:
0 - List current habits
View current habit streaks ( quitting-smoking )

1 - view 5 random quit-smoking resources
Receive 5 random resources to quit smoking

2 - generate an alternative activity
Get suggestions for things to do instead of smoking
 
3 - View health benefits from your hiatus
View the benefits of your decision to quit: life saved estimate, money saved estimate

4 - Manage habits ( add / record streak )
Enter your habit tracking data

5 - Exit program
Exit program
